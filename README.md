# Patient Appointment Form

A simple and basic webpage built using **HTML**, **CSS**, and **JavaScript** for registering hospital appointments.

## Form Fields
- **Patient ID**: Text input field (`patientId`)
- **Patient Name**: Text input field (`patientName`)
- **Department**: Dropdown selection menu (`department`)
- **Appointment Date**: Date picker input (`appointmentDate`)

## Action Buttons
- **Submit Button**: Validates inputs, shows an alert, and displays submitted appointment details in a table.
- **Reset Button**: Clears all form fields and resets the view.

## How to Open
Open `index.html` directly in any web browser.
